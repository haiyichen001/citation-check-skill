# Citation Check — 学术引用真实性验证

## 触发条件

用户提供包含学术引用的文本，或要求检查某段文字的引用是否造假。

## 工作流程

### 第一步：提取引用

从用户提供的文本中提取所有参考文献/引用，识别以下格式：

- **APA**: `Author (Year). Title. Journal, Volume, Pages.`
- **MLA**: `Author. Title. Publisher, Year.`
- **IEEE**: `[N] Author, "Title," Journal, vol. X, pp. X-Y, Year.`
- **Chicago**: `Author. "Title." Journal Volume (Year): Pages.`
- **自然语言引用**: "Smith et al. (2020) found that..."
- **ArXiv ID**: `arXiv:2106.09685` 或 `2106.09685`
- **DOI**: `10.xxxx/xxxxx`
- **URL**: 指向论文的链接

识别每条引用的关键字段：标题、作者、年份、期刊/会议、DOI/ArXiv ID（如有）。

### 第二步：分类优先级

按可验证性排序：

1. **有 DOI 或 ArXiv ID** — 最高优先级，直接精确查证
2. **有完整标题 + 作者 + 年份** — 可通过标题精确搜索
3. **只有作者 + 年份 + 期刊名** — 需组合搜索，准确性下降
4. **仅有模糊描述** — 如 "a study by MIT researchers"，几乎无法验证

### 第三步：逐条查证

对每条引用，按以下顺序使用工具：

1. **有 DOI**: 用 `mcp__scholar__get_paper` 按 DOI 查询
2. **有 ArXiv ID**: 用 `mcp__arxiv__get_abstract` 查询
3. **有标题**: 用 `mcp__scholar__search_papers` 或 `mcp__arxiv__search_papers` 按标题搜索
4. **只有作者+年份**: 用 `mcp__scholar__search_papers` 组合搜索作者和关键词
5. **中文文献**: 用 `mcp__paper-search__search_google_scholar` 搜索，必要时用 WebSearch 查知网/万方

查证要点：
- 论文是否真实存在
- 标题是否匹配（允许标点、大小写差异，但核心内容必须一致）
- 作者是否匹配（至少第一作者/通讯作者吻合）
- 年份和期刊/会议是否匹配
- 如发现存在但信息有出入，标记为 "部分匹配" 而非直接标假

### 第四步：输出报告

输出结构化验证报告，每条引用标注状态：

| 状态 | 含义 |
|------|------|
| ✅ 已验证 | 论文存在，关键信息匹配 |
| ⚠️ 信息有出入 | 论文存在，但作者/年份/期刊等有误 |
| ❌ 伪造引用 | 核心信息（标题/作者组合）无匹配结果 |
| 🔍 无法验证 | 信息不足，无法有效查证 |

报告格式：

```
# 引用验证报告

**检查文本**: [用户提供的文本摘要]
**引用总数**: N
**验证通过**: N | **信息有出入**: N | **伪造**: N | **无法验证**: N

---

### [1] [引用原文]
- **状态**: ✅/⚠️/❌/🔍
- **查证结果**: [实际存在的论文信息]
- **差异说明**: [如有差异，具体列出]
- **证据**: [DOI/链接]

### [2] ...
```

### 注意事项

- 不要因为搜索排名低就判定为假——某些论文可能引用量少但确实存在
- 标题搜索时尝试不同组合（去掉标点、用引号括起关键短语）
- 对中文文献，知网/万方可能不在工具覆盖范围，标注为"无法验证"而非"伪造"
- ArXiv preprint 后来可能正式发表在不同期刊，年份和期刊名可能有合理差异
- 预印本（preprint）也是合法引用，不要因其未正式发表就标假
